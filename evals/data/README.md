# Local Evaluation Data

This directory is intentionally ignored by Git.

Restore externally stored datasets here before running data-dependent evals. The
current local layout is:

- `posttrain/multifamily-seed-r1/`
- `posttrain/pilot-r4/`
- `posttrain/real-drawings/`
- `sources/fusion360gallery/posttrain-fusion-r1/`

Do not commit raw PDFs, images, STEP files, Kimi sessions, or downloaded source
archives. Keep only scripts, manifests, schemas, and documentation in Git.
