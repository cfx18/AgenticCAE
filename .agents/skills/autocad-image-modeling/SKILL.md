# AutoCAD

Use the `autocad` MCP server to work with a running local AutoCAD instance.

`autocad_send_command` accepts complete AutoCAD command-line input or AutoLISP expressions, so use whichever AutoCAD operations are appropriate for the requested design. Other tools expose document status, system variables, document creation, and saving.
